A desk bot that is made using XIAO ESP32S3 and a NEO-6M GPS and a 1.3inch OLED. HIs name is alfred and he uses the GPS instead of an IMU and rtc time module to detect shake and time. When I shake it the speed goes up high and GPS detects it , this makes the desk companion show some fun animations, like when someone is feeling sick then dizzy then getting better and finally it shows a clock. The time, on this clock comes from the GPS UTC.
